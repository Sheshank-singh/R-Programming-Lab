# Experiment 1

# Air-Quality Data Cleaning Using R

## Aim

Develop an R program to clean the Beijing Multi-Site Air Quality Dataset using loops, user-defined functions, and error handling.

## Dataset

Beijing Multi-Site Air Quality Dataset

Station Used:

PRSA_Data_Aotizhongxin_20130301-20170228.csv

## Tasks Performed

- Imported the dataset
- Inspected dataset structure
- Demonstrated NA, NULL and NaN
- Created missing-value summary function
- Created pollution_ratio feature
- Identified NaN and Infinite values
- Applied median imputation
- Applied mode imputation
- Implemented tryCatch() error handling
- Generated comparison table
- Created grouped bar chart
- Exported cleaned dataset
