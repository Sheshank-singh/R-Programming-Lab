# Experiment 05 — Social Network Analysis with R

## Domain

Social Network Analysis and Graph Theory

## Objective

The objective of this experiment is to perform Social Network Analysis (SNA) using R to understand relationships, connections, and interaction patterns within a network.

The analysis focuses on representing relationships as a network, examining its structure, identifying important nodes, and visualizing connections between entities.

Network analysis techniques are used to understand connectivity, centrality, and the overall organization of the network.

## Dataset

**Social Network Dataset**

The dataset represents a collection of entities and the relationships between them. Each entity is represented as a node, while each relationship is represented as an edge.

Depending on the dataset used in the R notebook, the data may contain:

- Node identifiers
- Source and target nodes
- Relationships between entities
- Node attributes
- Edge attributes or relationship weights

The dataset is used to construct a network graph and perform structural analysis.

### Task 1 — Data Loading and Preparation

The dataset was loaded into R and inspected before constructing the network.

The analysis includes:

A network graph was constructed using the available relationship data.

- Creating a graph object

### Task 3 — Network Properties and Structural Analysis

The network structure was examined using graph-based measures.

The analysis may include:

- Number of vertices and edges
- Node degree
- Network density
- Connected components
- Degree distribution
- Network connectivity

These measures help describe how entities are connected within the network.

### Task 4 — Centrality Analysis

Centrality measures were used to identify important or influential nodes in the network.

The analysis may include:

- **Degree centrality:** Measures the number of direct connections a node has.
- **Betweenness centrality:** Measures how frequently a node lies on shortest paths between other nodes.
- **Closeness centrality:** Measures how close a node is to other nodes through shortest paths.

The centrality results help identify nodes that play important roles in the network structure.

### Task 5 — Network Visualization

The network was visualized using R to make its structure and relationships easier to understand.

The analysis may include:

- Displaying nodes and edges
- Using graph layouts to arrange nodes
- Highlighting highly connected nodes
- Representing node importance through visual attributes
- Examining clusters and connection patterns

### Task 6 — Interpretation of Network Results

The network measures and visualizations were used to interpret the relationships within the dataset.

The interpretation focuses on connectivity, node importance, and the structural patterns observed in the network.

The conclusions are based on the results generated by the R analysis.
